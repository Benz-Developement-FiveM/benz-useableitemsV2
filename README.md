----------------------------------------------------------------------------------------------
Edible items for qb-core/ox_inventory. Makes it so you have more items in your server. Including food, drinks, alcahol, hunting, hacking, usbs, ids, memberships, mechanic, illegal, materials, drugs, etc
----------------------------------------------------------------------------------------------
REQUIREMENTS:

latest qb-core/qbox build

qb-smallresources (only for qb-core)
----------------------------------------------------------------------------------------------
INSTALLATION:

STEP 1

Put images into inventory image folder (any qb/qbox inventory will work)
----------------------------------------------------------------------------------------------
STEP 2

copy the items from qb-core/items.lua or if on qbox then ox_invetory/items.lua (at the bottom)

paste the items into your qb-core/shared/items.lua or ox_inventory/data/items.lua (at the bottom)
----------------------------------------------------------------------------------------------
STEP 3

copy the contents from qb-smallresources/config

paste the contents into your qb-smallrecources/config ((around line 91)(ends around line 134))
